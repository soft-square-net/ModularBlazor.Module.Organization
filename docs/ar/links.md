# روابط المستأجرين (هيكل أولي)

[English](../en/links.md)

**رابط المستأجرين** (tenant link) يصل مستأجرين شقيقين من المؤسسة نفسها: وحدة من مستأجر (`fromSeedId` و`fromUnitId`)
تتصل بوحدة من مستأجر آخر (`toSeedId` و`toUnitId`). سيتمكن المستأجران المرتبطان من متابعة أفعال بعضهما عبر وحدة
Webhooks مستقبلية. في هذا الإصدار التجريبي الرابط **هيكل أولي**: البيانات وحالاتها موجودة، ولا شيء يعمل بها بعد.

## الحالات

</div>

```
Requested ──accept──► Active ──revoke──► Revoked
    └──────decline──► Declined
```

<div dir="rtl">

| الحالة | المعنى |
| --- | --- |
| `Requested` | طلبه أحد المستأجرين (`requestedAt`) |
| `Active` | قبله الآخر (`decidedAt`) |
| `Declined` | رفضه الآخر (`decidedAt`) |
| `Revoked` | أُنهي رابط فعال |

لا يُقبل أو يُرفض إلا رابط مطلوب، ولا يُلغى إلا رابط فعال. والرابط يصل دائما مستأجرين مختلفين.

## الموجود

- `GET /api/organization/orgs/{orgId}/links` على الخدمة المركزية، وصفحة **روابط المستأجرين**، تعرضان روابط المؤسسة.
- كل تغيير حدث `org.tenant-link-changed.v1` في تغذية المؤسسة. ويحفظ موصل كل نشر في النسخة المتماثلة الروابط التي تسمي
  بذرة مستأجره، ويعيد نشر الحدث في ذلك المستأجر.

## غير الموجود بعد

- لا نقاط نهاية لطلب رابط أو قبوله أو رفضه أو إلغائه: لا تُنشأ الروابط عبر الواجهة البرمجية بعد.
- لا قدرات: الرابط الفعال لا يمنح شيئا ولا يحمل أفعالا.
